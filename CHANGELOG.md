# Title Text Overhaul — Changelog

This changelog tracks Title Text Overhaul releases published through GitHub.

Title Text Overhaul was originally released through XIV Mod Archive before the GitHub repository was established.

## 2.1.1

### Added

* Added a new custom-requested **Nordic Style** for:

  * Quest Accepted
  * Quest Completed
  * Duty Commenced
  * Duty Failed
  * Duty Complete
  * FATE Joined
  * FATE Failed
  * FATE Complete

### Updated

* Restored missing title textures that were affected during the move to Heliosphere.
* Cleaned up and reorganized the mod's JSON configuration for easier maintenance.

### Fixed

* Fixed an issue that could prevent the `.pmp` package from importing or implementing correctly in Penumbra after updating the mod.

---

## 2.1.0

Title Text Overhaul was already in active development before GitHub release tracking was established.

Version 2.1.0 represents the previous release prior to the introduction of the Nordic Style and the fixes included with 2.1.1.

## Previous Releases

Earlier versions of Title Text Overhaul were distributed outside of GitHub before GitHub release tracking was established.


### Mod Coverage

Title Text Overhaul currently includes redesigned title and announcement elements for supported content, including:

* Areas & Locations
* Dungeons
* Trials
* Normal & Savage Raids
* Alliance Raids
* Hard & Extreme content
* Quest & Duty announcements
* FATE announcements
* Light & Full Party messages

Additional title textures and expansion coverage will continue to be added in future releases.
